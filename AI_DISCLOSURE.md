# AI Use Disclosure

Tool: OpenAI ChatGPT.

In this project, OpenAI ChatGPT was utilized as an assistive tool for data preprocessing steps, drafting code blocks for model training, preparing output CSV templates, running experiments, and comparing experiment results and consistency metrics.
The AI assisted in accelerating the development pipeline and structuring the technical templates. However, all generated code blocks were thoroughly reviewed, and the final results were verified and validated independently. All project decisions, presentation preparation, and the narrated video recording were completed entirely by myself.
